# WordQuest AI — iPad / PWA

Це веб-додаток, який після публікації відкривається на iPad у Safari.
Після цього Safari → Поділитися → «На початковий екран», і він виглядає як окрема програма.

## Можливості
- власні набори карток;
- AI-генерація наборів з теми;
- ручне редагування;
- флеш-картки;
- тест;
- введення відповіді;
- Match;
- локальне збереження наборів і прогресу;
- PWA / додавання на Home Screen.

## Важливо про AI
API key НЕ знаходиться у браузері. Він використовується тільки у serverless endpoint `/api/generate`.
Потрібно додати змінну середовища:
OPENAI_API_KEY=ваш_ключ

## Найпростіший запуск через Vercel
1. Завантаж цей проєкт у GitHub.
2. На vercel.com обери New Project → імпортуй репозиторій.
3. У Settings → Environment Variables додай OPENAI_API_KEY.
4. Deploy.
5. Відкрий отримане посилання на iPad у Safari.
6. Share → Add to Home Screen.

Для локального тесту:
npm install
npx vercel dev
